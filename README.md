# linguagem-em-jogo
Plataforma educacional gamificada para a Feira de Linguagens, unindo tecnologia, Português e inclusão social. Oferece atividades interativas, níveis progressivos, avatares personalizados, narração por voz, acessibilidade e dashboard para acompanhar o desempenho dos alunos e gerar relatórios pedagógicos. Desenvolvida com React, JavaScript e CSS.
